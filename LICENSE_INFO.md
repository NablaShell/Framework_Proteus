# Лицензионная информация

## Тип лицензии
**Source-Available** — исходный код доступен, но с ограничениями на коммерческое использование.

## Основные положения

### ✅ Разрешено
- Просмотр и изучение кода
- Модификация для личных целей
- Не коммерческое использование
- Образовательные цели
- Частное тестирование

### ❌ Запрещено без соглашения
- Коммерческое использование
- SaaS сервисы
- Встраивание в коммерческие продукты
- Генерация дохода с использованием ПО

### 📋 Обязательства
- Атрибуция "Powered by Project Proteus"
- Ссылка на официальный репозиторий
- Соблюдение условий при коммерческом использовании

## Коммерческое использование

Для коммерческого использования необходимо:
1. Связаться с NablaShell
2. Заключить Franchise или Commercial Agreement
3. Согласовать роялти (3-5% от Gross Project Revenue)

## FAQ

### Могу ли я использовать для обучения?
✅ Да, для личного образования и некоммерческих целей.

### Могу ли я модифицировать код?
✅ Да, для некоммерческих целей.

### Могу ли я использовать в своем проекте?
❌ Только с письменного разрешения и заключения соглашения.

### Что считается коммерческим использованием?
- SaaS сервисы
- Платные продукты
- Встраивание в коммерческое ПО
- Любая деятельность, генерирующая доход

### Как получить коммерческую лицензию?
Связаться с NablaShell и заключить соглашение.
